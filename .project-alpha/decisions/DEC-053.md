# Decision Record

- Decision ID: DEC-053
- Stage: 04-prd
- Title: Store open debts to cure the slow overview of a very large shop
- Decision: Each debt not yet fully paid is stored with what is left of it and its promised date, in a table kept by the database from the ledger, beyond the approved schema. The founder first chose a stored balance; the agent measured that it would not help and said so, and he then chose this
- Context: Answered by the founder on 2026-10-07 when asked by the agent in the working session
- Chosen option: Table open_debt maintained by triggers; the ledger stays the only truth
- Rationale: A stored balance gives the total owed but not the overdue figures; storing the open debts took the overview's totals for a shop of 200 298 entries from 361 ms to 2.3 ms on the generated load database
- Impact: High
- Reversibility: High
