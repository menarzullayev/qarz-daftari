# Stage Contract — 05 Domain Model

## Preconditions
04 PRD is PASSED.

## Inputs
PRD, business rules, user flows, approved product decisions.

## Agent task
Model entities, value objects, aggregates, relationships, invariants, lifecycle rules, and domain constraints. Identify ambiguities before architecture.

## Outputs
Completed domain model using `TEMPLATE.md`.

## Human approval
Required when domain boundaries or core business rules have high product or migration impact.

## Handoff
Provide stable domain concepts and business rules for Architecture and Technical Specification.
