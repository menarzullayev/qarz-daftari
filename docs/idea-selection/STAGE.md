# Pre-Pipeline Contract — Idea Selection

## Purpose
Select which idea should enter the 10-stage product documentation pipeline.

## Inputs
Candidate ideas, available evidence, founder constraints, market signals, and known risks.

## Agent task
Evaluate candidates using explicit criteria such as problem severity, willingness to pay, market potential, differentiation, MVP feasibility, distribution, founder advantage, regulatory risk, and evidence quality. Stress-test the leading candidates.

## Outputs
A selected idea, rejected/parked alternatives, evaluation rationale, evidence, assumptions, and required human decision.

## Human approval
Required before an idea enters Stage 01.

## Handoff
Create project configuration and initialize Stage 01 with the selected idea and decision record.
