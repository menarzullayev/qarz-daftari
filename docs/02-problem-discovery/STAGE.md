# Stage Contract — 02 Problem Discovery

## Preconditions
01 Vision is PASSED.

## Inputs
Vision, project context, research evidence, assumptions.

## Agent task
Identify target users, pains, jobs-to-be-done/use cases, problem severity, current alternatives, and measurable success metrics. Separate observed evidence from hypotheses.

## Outputs
Completed problem discovery document using `TEMPLATE.md`.

## Human approval
Required when selecting the primary target user/problem or materially changing product direction.

## Handoff
Produce validated problem statements and success metrics for Market Research and PRD.
