# Evidence Record

- Evidence ID: EVID-027
- CLAIM: Uzbekistan's Law on Personal Data requires personal data of Uzbek citizens to be collected and stored on servers physically located in Uzbekistan (Article 27-1, in force since 15 April 2021) and the database to be registered in the State Register before processing; valid consent must name the operator, the purposes and the data; exemptions exist for some internal and non-automated processing. Enforcement has been uneven and the rule's interpretation is debated. Penalty amounts were not found.
