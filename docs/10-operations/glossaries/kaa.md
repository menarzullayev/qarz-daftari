# Karakalpak (kaa) glossary

The Karakalpak texts of Qarz Daftari use the **current official Latin alphabet (the 2016 revision)**:
Á á, Ǵ ǵ, Í ı (dotless ı for the back vowel, plain I i for the front one), Ń ń, Ó ó, Ú ú, and
Sh sh, Ch ch, W w, Y y, X x, H h, Q q, C c. No apostrophe letters of the 1995/2009 alphabet (a', g', o',
u', n') and no Cyrillic, except the language autonyms that are copied verbatim.

The texts were written by a model and have not yet been reviewed by a native speaker. Uzbek (Latin) is
the source; each term below is used the same way in every catalog (frontend, chat, exports, API
refusals, permission names).

## Conventions

- Polite "Siz" throughout; imperatives end in -ń (kiritiń, tańlań).
- A noun stays singular after a number, and the Uzbek classifier "ta" is dropped: "{count} qarıydar".
- Where Uzbek attaches a case ending to a placeholder ("{date} gacha", "{min} dan {max} gacha"), the
  Karakalpak text uses a carrier word so vowel harmony never depends on the value: "{date} kúnine
  shekem", "{date} kúni", "{min} – {max} aralıǵında".
- Month names: yanvar, fevral, mart, aprel, may, iyun, iyul, avgust, sentyabr, oktyabr, noyabr, dekabr.
  Dates read "{year}-jıl {day}-{month}".
- Text the bot must parse is left exactly as in Uzbek, because the parser reads Uzbek and Russian only:
  `Ali 45000`, `Ali -20000`, `Ali 20000 berdi`, `Ali 45000 non, sut`, `25.10`, `45k`, and every command
  (`/obuna`, `/til`, `/dokon`, `/yordam`, `/qarzim`, `/uzish`, `/ochirish`, `/start`).
- SMS templates exist in Uzbek and Russian only; there are no Karakalpak SMS texts.
