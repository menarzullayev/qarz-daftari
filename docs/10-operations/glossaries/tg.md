# Tajik (tg) glossary

The Tajik texts of Qarz Daftari are written in **Cyrillic script, in standard literary Tajik** with the
letters ғ, ӣ, қ, ӯ, ҳ, ҷ, as used in Tajikistan and by Tajik speakers in Uzbekistan. The register is
everyday shop language with the polite plural «Шумо» (capitalised); where a plain word and a bookish
Persian or Russian one compete, the plain one is used.

The texts were written by a model and have not yet been reviewed by a native speaker. Uzbek (Latin) is
the source; each term below is used the same way in every catalog (frontend, chat, exports, API
refusals, permission names).

## Conventions

- **Never translated:** the product name `Qarz Daftari`, bot commands (`/obuna`, `/til`, `/dokon`,
  `/yordam`, `/kassa`, `/qarzim`, `/uzish`, `/ochirish`, `/start`), `Telegram`, `SMS`, `QR`, `PDF`, `Excel`, `CSV`,
  `UUID`, file extensions, and the language autonyms (`O'zbekcha`, `Русский`, `Ўзбекча`, `Тоҷикӣ`,
  `Qaraqalpaqsha`, `English`).
- **Typed examples stay Uzbek.** The chat parser reads Uzbek and Russian input only, so the example
  lines (`Ali 45000`, `Ali -20000`, `Ali 20000 berdi`, `Ali 45000 non, sut`, `Ali 45000 izoh`, `45k`,
  `45 ming`, `25.10`, `Ali 50$`) are copied from the Uzbek text; only the words around them are Tajik.
- **Numbers.** A noun stays singular after a number («5 мизоҷ», «3 рӯз»), so every plural entry has the
  single form `other`. The Uzbek counter «ta» is dropped before a noun and kept as «то» where the number
  stands alone («{used} то»).
- **Dates.** Month names are the standard forms (январ, феврал, март, апрел, май, июн, июл, август,
  сентябр, октябр, ноябр, декабр). A day and month read «6 октябр»; with the year the month takes the
  izofat written straight after the placeholder: `{day} {month}и {year}` → «6 октябри 2026».
- **Suffixes after a placeholder or a Latin word** are joined with a hyphen: «Telegram-и худ»,
  «{date}-ро», «PDF-ро».
- **Questions that confirm an action** use the passive subjunctive («… бекор карда шавад?») and the
  answer button repeats the verb («Ҳа, бекор шавад»).
